# Portofolio

Dokumentasi dari Portofolio saya yang dibangun menggunakan React dan Vite.

## Tech Stack
- React 19
- Vite
- Bootstrap 5 & React Bootstrap
- React Icons

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   # atau
   pnpm install
   ```

2. **Jalankan server development:**
   ```bash
   npm run dev
   ```

3. **Build untuk produksi:**
   ```bash
   npm run build
   ```
